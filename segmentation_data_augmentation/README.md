# Segmentation Data Augmentation

Pascal VOC 형식의 이미지와 segmentation mask에 동일한 공간 변환을 적용하는 과제입니다.

- rotate, crop, flip, blur, scale, and translate
- partial erase, stitch, and copy-paste
- bilinear interpolation for images and nearest-neighbor interpolation for masks
- mask colorization and overlay visualization
